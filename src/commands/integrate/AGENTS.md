# Integrations and runtime hooks

This guidance also applies to `src/commands/hook/`, `context/`, and `analyze/`. Read [the framework guidance](../../core/framework/AGENTS.md) before changing declarative assets.

- Agent handlers use `finalizeAgentInstall`; declare capabilities through shared feature factories rather than duplicating install, prompts, state recording, or completion output. Integrations install globally; Git's `--local` exception must consult local `core.hooksPath` only, never overwrite an inherited global hook.
- Keep one owner per resource. Use containers/subfeatures for genuinely shared assets; add dispatch machinery only when an event has multiple subscribers. Removing one feature must preserve unrelated user settings and other features' assets.
- Use shared hook command builders for quoting and target resolution. Claude project paths need the expandable `CLAUDE_PROJECT_DIR` placeholder, double-quoted on Unix and Windows. Global paths are absolute. Preserve each agent's actual payload schema, blocking decision, and output channel.
- Secrets handlers fail closed when dependencies/scanning/masking fail. Do not confuse failed Git enumeration with an empty result: pre-commit/pre-push must refuse on lookup failure. Generated launcher failure behavior differs across agents; test it explicitly rather than assuming every launcher is fail-closed.
- User-facing SQAA wording is **Vortex analysis**. Reuse shared Vortex factories, entitlement resolution, and instruction templates. Preserve installed features on an entitlement-check failure; remove them only after confirmed loss/not-applicable. Consumption limits do not block installation.
- Resolve projects at runtime. Route each edited file to its owning project and keep server paths relative to that project's analysis root, distinct from display paths. Read [state/auth guidance](../../../docs/development/agent-guidance/state-and-auth.md) for discovery. Per-edit analysis uses STANDARD; end-of-turn instructions request DEEP even for one file.
- Context passthrough preserves arguments and child exit codes, and carries the invocation correlation id. Session-start warnings must not block startup. Retain cross-platform shell and agent protocol tests for changes to generated hooks.
- Protocol writers may create client-specific instruction files. Preserve managed blocks and markers when editing them; avoid duplicating repository rules. A generated `CLAUDE.md` can suppress native `AGENTS.md` loading, so verify loading or import `@AGENTS.md` when that file must exist. Do not run `sonar integrate` in this checkout to validate documentation loading.
